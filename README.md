# 分投侠 (Fentouxia) - 智能垃圾分类助手

分投侠是一款集合了人工智能垃圾分类图像识别、智能对话、环保社区、地图垃圾桶定位寻路及积分商城系统于一体的综合性环保应用项目。本项目旨在运用 AI 与物联网（IoT）技术，帮助用户轻松掌握垃圾分类知识，并激励社区建立良好的环保环保习惯。

本项目由前端（`front-head`）与后端（`back-end`）两部分组成。

---

## 🌟 核心功能特性

### 1. 📷 智能分类与图像识别
- **AI 拍照识别**：通过调用后端的深度学习（YOLO算法）推理引擎，实现在端侧拍照上传并毫秒级识别各类垃圾（干垃圾、湿垃圾、可回收物、有害垃圾）。
- **RAG 智能环保大模型问答**：结合向量检索（Faiss）与自然语言处理，提供基于专业环保知识库的智能对话服务，解答各种垃圾处理疑惑。

### 2. 🗺️ 便捷地图与设备互联
- **垃圾桶地图寻路**：实时获取用户地理位置，在地图上展示附近的智能垃圾桶及回收点，并提供导航。
- **智能设备操控**：用户可以与实体智能垃圾桶（设备模拟器）相互绑定，实时查看容量、下达指令或记录投递动作。

### 3. 👥 环保社区与激励机制
- **动态交流社区**：用户可在应用内发贴、评论、点赞，分享自己的低碳环保生活日常，建立社交连接。
- **积分反馈与商城系统**：完成分类、答题或投递垃圾后可获取环保积分。获得积分可以在商城 (Shop) 中兑换奖品，或参与抽奖转盘 (Lottery)。
- **在线答题挑战**：题库挑战模式，不仅能提升环保意识，还能增加应用趣味性和积分获取途径。

### 4. ♻️ 上门回收与调度规划
- **回收预约**：用户可一键预约回收人员上门收集废品。
- **采集路线规划**：后端提供针对社区及废品站的回收路径智能规划。

## 🛠️ 技术栈与项目结构

### 🎨 前端 (Front-end)
前端部分位于 `front-head` 目录下，采用跨平台应用开发框架开发，能够一键打包发布至微信小程序及 H5 平台。
- **核心框架**：[UniApp](https://uniapp.dcloud.io/) (基于 **Vue 3**)
- **构建工具**：Vite
- **状态管理**：Vuex (兼容支持)
- **主要特色模块**：
  - 各类原生 API 适配（摄像头扫描、地理定位、地图 SDK）。
  - WebSocket 实现聊天实时通信与设备状态更新。
  - Vue-i18n 多语言国际化支持。

### ⚙️ 后端 (Back-end)
后端部分位于 `back-end` 目录下，负责承载业务逻辑处理、硬件通信、与 AI 模型服务的调用集成。
- **核心框架**：Node.js + Express
- **数据库 ORM**：Sequelize，支持多表结构如：用户(User)、设备(Device)、垃圾桶(Bin)、社区(Community)、商店(Shop) 等核心实体。
- **人工智能库接入**：
  - 计算机视觉识别：基于 `best.pt` 的 Python YOLO 目标识别脚本（通过进程通信调用）。
  - 知识图谱 / 向量库：使用 Neo4j 及 Faiss 维护和检索本地化知识库（`rag_data`），作为大语言模型的底层支撑。
- **通信支持**：HTTP RESTful APIs + WebSocket 用于保持客户端和物联网设备的双向通讯。

## 🚀 快速启动

### 后端服务启动
1. 进入 `back-end` 目录
2. 安装依赖：`npm install`
3. 配置环境变量：将 `.env.example` 复制为 `.env` 并按需配置数据库以及各项 API 密钥。
4. 运行服务：`npm run dev` (使用 nodemon 开启开发模式)

### 前端页面运行
1. 进入 `front-head` 目录
2. 安装依赖：`npm install`
3. 运行本地开发服务器 (H5平台)：`npm run dev:h5` 
4. 若需微信小程序端运行，则执行：`npm run dev:mp-weixin` ，并在微信开发者工具中导入对应编译后目录 (`dist/dev/mp-weixin`)。

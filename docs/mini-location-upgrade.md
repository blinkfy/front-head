# 微信小程序定位升级

微信后台已开通的接口还需随新版小程序发布。`manifest.json` 声明了使用中的私有定位接口；收货地址簿通过 `chooseAddress` 调起，不属于 `requiredPrivateInfos` 的定位接口列表。发布前需在微信后台的隐私保护指引中核对地理位置、收货地址、姓名和电话的实际用途。

## 使用与回退

| 场景 | 默认方式 | 回退 |
| --- | --- | --- |
| 聊天发送位置、档案选址、商城地图选址 | `chooseLocation` | 接口缺失或不支持时尝试 `choosePoi`；只接受具体地点，不接受城市坐标。聊天还可手动打开原有地图选点；地址表单保留手填。取消或拒绝用户授权不自动再弹一个选择器。 |
| 商城收货信息 | 手填、地图选址或主动点击“微信收货地址” | 地址簿取消不改原值；只有明确选用地址簿才填收货人和电话。之前拒绝地址授权时，再点击可进入设置恢复授权。 |
| 地图、档案和地址定位 | 共用 `getLocation` 获取精确坐标 | 定位失败不写入默认坐标，保留手动选择、填写和重试。 |
| 实时共享 | `startLocationUpdate` + `onLocationChange`，WGS84 | 持续定位接口缺失、启动失败、运行异常或迟迟不更新时，前台自动改用 `getLocation`，每次完成后等待15秒再采样。拒绝授权不通过其它接口继续定位。 |

兼容策略自动选择，不提供用户开关。每次开始或恢复共享时优先尝试持续定位，发生非授权类异常时，本次共享自动回退到定时定位；兼容定位也失败则停止并显示重试入口。取消或拒绝授权时直接停止，不尝试其它定位方式。旧版开关的本地缓存不再生效。不修改数据库、AI开关或其它端配置。

## 实时共享边界

- 使用小程序原生地图和页面，无需打开内嵌网页。聊天中主动发起或点击对方邀请后才开始定位。
- 小程序内可返回聊天继续共享。切到其它 App 或锁屏后暂停定位，返回前台会通过原有会话重新加入；若双方均已离开、服务端会话已结束，则需重新发起。
- 未接入 `startLocationUpdateBackground`，不承诺小程序后台持续定位。
- 主动退出、账号更换或页面启动取消后，旧回调不能继续发布坐标；原生监听按会话清理，启动与停止串行处理。
- 坐标复用现有聊天 WebSocket：移动时最多约5秒一次，静止时约30秒；兼容采样可能更慢。坐标不新增数据库写入，不新增后端轮询、连接或坐标解析请求。
- 老后端未提供 `liveLocationVersion: 1` 时不展示新共享入口，已有地址与普通地图功能照常使用。

## 真机验收

在手机微信测试：首次允许定位、拒绝后再次点击恢复、选点取消保留原值、地址簿填入姓名电话、APP/网页与小程序互相共享、返回聊天继续、切后台暂停后回前台恢复、双方退出结束。模拟持续定位接口不可用、启动失败、运行中异常和无位置回调，验证自动兼容及退出清理；开发者工具不能代替真机的权限和前后台行为验证。
